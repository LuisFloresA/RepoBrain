# Demo embebida de RepoBrain

Mini proyecto "login-api" en Python (FastAPI) + JavaScript usado como
**repo de ejemplo pre-indexado** para el modo demo, sin necesidad de red ni
API key.

Busca, por ejemplo:

- "¿dónde se valida el JWT?" → `app/auth.py`
- "¿cómo se hace el soft delete?" → `app/models.py`
- "¿en qué archivo está la conexión a la base de datos?" → `app/db.py`
